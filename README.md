# SagaApp - Markdown Editor

A modern Markdown editor with built-in terminal and Git integration, built with Electron and TypeScript.

## Features

- **Markdown Editor** - Full-featured CodeMirror-based editor with syntax highlighting
- **File Explorer** - Sidebar with file tree navigation
- **Outline View** - Document structure with heading hierarchy
- **Terminal** - Integrated terminal emulator
- **Git Integration** - Basic Git commands (commit, push, pull, branch management)
- **Preview Mode** - Live Markdown preview
- **Multiple Themes** - Dark, Light, and Glass themes

## Development

This project is currently under development.

### Prerequisites

- Node.js 18+
- npm 9+

### Installation

```bash
npm install
```

### Development Mode

```bash
npm run dev
```

### Build

```bash
npm run build
```

## Tech Stack

- **Electron** - Desktop application framework
- **TypeScript** - Type-safe JavaScript
- **CodeMirror 6** - Extensible code editor
- **xterm.js** - Terminal emulator
- **node-pty** - PTY for terminal
- **marked** - Markdown parser
- **DOMPurify** - HTML sanitization
